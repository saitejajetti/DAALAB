Summary
Max Heap Sort is a comparison-based sorting algorithm that first builds a Max Heap and then repeatedly removes the largest element to sort the array. It sorts the elements in ascending order.

Best Case: O(n log n)
Average Case: O(n log n)
Worst Case: O(n log n)
Space Complexity: O(1)

Conclusion

Max Heap Sort provides consistent O(n log n) performance in all cases and does not require extra memory for sorting. It is useful when predictable performance and low space usage are important
