Summary
Linear Search: Checks each element one by one. It works on both sorted and unsorted arrays.
Binary Search: Repeatedly divides the search range into half. It requires the array to be sorted.
Linear Search: O(n) in the average and worst cases.
Binary Search: O(log n) in the average and worst cases.

Conclusion:

Linear Search is simple and useful for small or unsorted data. Binary Search is much faster for large datasets, but the data must be sorted first. Therefore, Binary Search is preferred when the data is sorted and efficient searching is required.
